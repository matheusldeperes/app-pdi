CONFIGURAÇÃO DOS LOGOS

O sistema agora suporta logos diferentes para temas dark e light:

1. Para o tema DARK: coloque o arquivo "logo_dark.png" na raiz do projeto
2. Para o tema LIGHT: coloque o arquivo "logo_light.png" na raiz do projeto
3. Fallback: se os arquivos específicos não existirem, o sistema usa "logo.png"

O sistema detecta automaticamente qual logo usar baseado no tema ativo do Streamlit.
